# 实用测试版 v1：交付与记录说明

版本：20261029-practical-test-v1。用户已授权先交付可用版本，由用户测试后再分析记录。

## 本次交付

现有面板 8900 与分析服务 8892 已接入实用测试模式。核心是原启发式、所有活跃对手的联合权益、整手公开行动、原有收缩玩家统计与金额/过期检查。没有启用新增尺度学习模型、全街随机续局或自我训练。它是近似建议，尚未证明实战强度。

服务通过 POKER_SOLVER_MODE=practical 选择 practical_api.py，默认环境下旧 API 保留以便恢复。recommendationReady 仅表示测试建议满足本次输出条件，不表示 GTO 认证。输出无伪造的混合频率、行动 EV 或胜率保证。缺少完整投入账本、边池资格不明、金额非法或抽样足以改变建议时，会保留而不强行给动作。

界面放大行动和可核对的金额，按动作着色，标记“实用测试版”。下方可评价最近建议或选择最近决策：合理、有疑问、明显不合理，并可填写原因。已选择的评价目标不会被下一手自动替换，防止反馈串手。

## 本机测试方式

打开 http://127.0.0.1:8900/，建议从一手新牌开始，让记录包含完整行动历史。等实际轮到自己时查看建议。需要评价时先点击“评价最近建议”或对应历史行的“评价”，核对目标手牌/街道，再选择评价并填写可选说明。你可以照自己的判断行动。

没有新牌输入时等待界面不会伪造建议。采集守护延续原流程；游戏重开产生新文件时桥会自动切换。若从中途才观察到本手，部分建议可能因账本不完整而保留。

## 记录在哪里

全部保留在本机原 pokerist-gto 运行目录：

- advice-live.jsonl：当时局面、返回的建议/拒绝原因、计算时间。
- observations.jsonl：实际行动、当时已返回的分析、可核对的结算。
- user-feedback.jsonl：用户评价、说明及绑定的完整局面和已显示分析。
- player-profiles.json：持续按玩家 ID 记录的原有统计。

这些记录按 decisionId/handId 关联。与建议不同的行动被记作 different_test_action，不判作错误，也不虚构 EV 损失。结算仍按守恒核验；单手输赢不会自动训练成“策略正确性”标签。后台训练与复盘训练进程在这个测试版本中均关闭，等待用户测试后的集中分析。

## 验证和恢复

70 项相关 Python 检查通过，四个 Node 桥接/界面/账本/反馈测试入口通过；原引擎 98 项检查通过。真实 /solve 请求对三个归档合法场景返回小额加注、过牌、弃牌，约 0.40–0.45 秒；一个投入不守恒场景被拒绝。反馈通过真实 HTTP 测试确认落盘、拒绝错误 ID 与异源请求。过期/取消请求不保留建议。

这些是工程与指定局面验证，不是策略强度证明。部署时尚无新的真实牌局输入，等待用户开局测试。
